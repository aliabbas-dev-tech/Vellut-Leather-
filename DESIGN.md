# Vellut Leather Design System

## Global Colors
- **Cream (Background):** `#fbfaf6`
- **White:** `#ffffff`
- **Beige (Secondary):** `#ebdccd`
- **Taupe (Accents/Text):** `#8b7d6b`
- **Soft Gold (Primary Accent/Hover):** `#d4af37`
- **Dark Charcoal (Main Text/Logo):** `#2c2a29`

## Typography
- **Headlines / Logo:** Elegant, classic Serif font (e.g., "Playfair Display" or "Mastle" equivalent).
- **Body / Menus:** Clean, modern Sans-Serif font (e.g., "Inter" or "Outfit").

## Layout & Components
- **General Feel:** Minimalist, High-End Boutique, Quiet Luxury, Clean.
- **Buttons:** Sharp borders, solid neutral colors with soft gold hover states. No heavy dropshadows, use subtle micro-interactions.
- **Spacing:** Generous padding, breathable layouts.
